### **Plan d’action (7 jours)**
**Objectif** : Maximiser la visibilité et les ventes via une campagne ciblée et progressive.

| **Jour** | **Action**                                                                 | **Outils/Canaux**               | **Durée estimée** |
|----------|----------------------------------------------------------------------------|----------------------------------|-------------------|
| **J1**   | **Préparation** : Finaliser les liens Amazon (FR/ES), vérifier la couverture, rédiger des extraits courts. | Google Drive, Canva (visuels)   | 1h                |
| **J2**   | **Lancement** : Publier le post principal sur LinkedIn + Twitter.          | LinkedIn, Twitter (X)           | 30 min            |
| **J3**   | **Relais** : Partager le post sur les groupes Facebook/Reddit dédiés (SF, écologie, littérature). | Groupes Facebook, Reddit        | 1h                |
| **J4**   | **Engagement** : Répondre aux commentaires, liker/partager les partages, relancer avec un extrait. | Réseaux sociaux                 | 30 min            |
| **J5**   | **Emailing** : Envoyer une newsletter (si liste existante) avec l’extrait + liens. | Mailchimp/ConvertKit           | 1h                |
| **J6**   | **Influenceurs** : Contacter 5 micro-influenceurs (1K–10K abonnés) spécialisés en SF/littérature pour un partage (échange gratuit contre un exemplaire). | Instagram, Twitter, emails      | 2h                |
| **J7**   | **Analyse** : Vérifier les stats (clics, ventes), ajuster le message si besoin, relancer un post "dernière chance". | Amazon KDP, Google Analytics    | 30 min            |

---
**Notes :**
- **Budget** : 0€ (sauf si achat d’espace publicitaire ciblé).
- **Flexibilité** : Adapter les jours 6–7 en fonction des retours (ex : si un influenceur répond tard).
- **Suivi** : Utiliser un outil comme **Bitly** pour tracker les clics sur les liens Amazon.

---

### **Éléments à vérifier**
1. **Liens Amazon** :
   - Vérifier que les liens FR/ES sont **corrects et fonctionnels** (pas de redirection vers une autre page).
   - Tester l’achat en mode "incognito" pour éviter les caches.
2. **Couverture du livre** :
   - S’assurer que la version numérique (Kindle) et papier (si applicable) sont **cohérentes** et sans erreur.
3. **Extrait** :
   - Choisir un passage **accrocheur** (début ou milieu du livre) qui donne envie sans spoiler.
4. **Hashtags** :
   - Vérifier leur pertinence (ex : #FableCosmique fonctionne mieux que #ScienceFiction classique).
5. **Réseaux cibles** :
   - Cibler les groupes/comptes **spécialisés** (ex : groupes Facebook "Science-Fiction Française", subreddit r/printSF).
6. **Disponibilité** :
   - Confirmer que le livre est **disponible en version Kindle et broché** (si applicable) sur les deux marchés.

---
**Prochaine étape** : Une fois la campagne lancée, analyser les **ventes sur 7 jours** et ajuster le message si nécessaire (ex : mettre en avant un aspect plus populaire).
